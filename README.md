# Classic Snake Game

A simple and fun Snake game implemented using Python's built-in `turtle` module. No external libraries required!

## Features
- Classic grid-based movement.
- Food collection and snake growth.
- Real-time score and high score tracking.
- Border and self-collision detection.

## Prerequisites
- Python 3.x (Built-in `turtle` module is included by default).

## How to Run
1. Navigate to the project directory.
2. Run the game using Python:
   ```bash
   python snake.py
   ```

## Controls
- **Up Arrow**: Move Up
- **Down Arrow**: Move Down
- **Left Arrow**: Move Left
- **Right Arrow**: Move Right

## How to Play
- Use the arrow keys to control the green snake head.
- Eat the red circles (food) to grow and increase your score.
- If you hit the wall or your own tail, the game will reset.
- Try to beat your high score!
